# RemindMe Privacy & Support

Statik gizlilik ve destek sayfaları. Harici bağımlılık, JavaScript, analiz veya reklam içermez.

- `index.html`: Türkçe ve İngilizce gizlilik politikası
- `support.html`: Destek iletişimi ve sık sorulan sorular
- `.nojekyll`: GitHub Pages üzerinde statik yayın

## GitHub Pages

Bu dizinin içeriğini `reminedme-privacy` deposunun köküne kopyalayın. GitHub Settings → Pages → Deploy from a branch → `main` → `/ (root)` seçin.

Yayın başarılı olduktan sonra beklenen adresler:

- Privacy Policy URL: `https://dalkilicyasin.github.io/reminedme-privacy/`
- Support URL: `https://dalkilicyasin.github.io/reminedme-privacy/support.html`

Bu adresler yayın tamamlanana kadar etkin olmayabilir.
